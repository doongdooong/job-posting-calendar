# 채용공고 캘린더

너무 많아서 트래킹이 힘든 채용공고를, 캘린더 한눈에 관리하는 개인용 도구.

## 배포

- **호스팅**: GitHub Pages, 이 저장소의 `index.html`
- **URL**: https://doongdooong.github.io/job-posting-calendar/
- **접근**: 아이폰 Safari → 공유 버튼 → 홈 화면에 추가 (PWA, 네이티브 앱 아님)

## 기능

- **캘린더 뷰**: 월간 그리드. 시작일+마감일이 있으면 여러 날에 걸친 막대로, 마감일만 있으면 당일 일정으로 표시. 우선순위(높음/중간/낮음)를 색으로 구분
- **목록 뷰**: 우측 상단 아이콘으로 전환. 회사명·직무·분류·마감일시를 한 줄씩, 지원중/지원완료 토글 포함
- **공고 추가/수정/삭제**: 회사명만 필수, 나머지(직무/분류/시작일/마감일·시간/공고링크/우선순위)는 전부 선택
- **필터**: 우측 상단에서 지원중/지원완료 상태로 캘린더·목록에 보이는 공고를 조절

## 데이터 저장

서버나 데이터베이스 없이, 브라우저의 `localStorage`에 전부 저장됨 (`index.html` 하나로 완결되는 정적 페이지).
→ **기기(브라우저)마다 별도로 저장**되고, 다른 기기에서는 보이지 않음. 여러 기기에서 동일하게 보려면
`archive/*.json`처럼 저장소 파일에 직접 데이터를 저장하고 `fetch`로 읽어오는 구조로 바꿔야 함
(참고: [newsletter-claude](https://github.com/doongdooong/newsletter-claude)의 방식).

## 파일 구조

```
index.html   # 웹앱 전체 (마크업 + 스타일 + 로직, 단일 파일)
```
